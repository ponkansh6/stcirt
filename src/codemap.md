# src/

## Responsibility

Source code for the Stcirt application frontend (Next.js App Router), API endpoints, UI components, and database repositories.

## Structure

- `app/` — Next.js pages (`/`, `/answer`) and REST API routes
- `components/` — Reusable Tailwind UI components (Button, NavLink, ResultBanner, ChoiceButton, etc.)
- `lib/` — Reusable utilities, database repositories, and API clients
- `types/` — Shared TypeScript definitions
