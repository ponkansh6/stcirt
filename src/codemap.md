# src/

## Responsibility

Source code for the Stcirt five-question exam, administration and presentation application (Next.js App Router), API endpoints, UI components, and database repositories. Product requirements are in `openspec/specs/stcirt/spec.md`.

## Structure

- `app/` — Next.js pages for exam entry, administrator presentation, public projection, participant results, and API routes
- `components/` — Shared UI components used by exam and presentation views
- `lib/` — Authentication, provider assessment, utilities, database repositories, and API clients
- `types/` — Shared TypeScript definitions
